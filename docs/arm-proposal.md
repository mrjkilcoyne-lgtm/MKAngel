## Context

At present, every significant AI system available to consumers
requires a graphics processing unit, a persistent connection to
servers located predominantly in the United States, and a recurring
subscription of sixteen to twenty pounds per month.

We have built an alternative.

**MKAngel** is a working artificial intelligence — 37 megabytes,
pure software, no external dependencies — that runs natively on
Arm Cortex-A processors. It comprehends natural language across
twelve human languages and six British dialects. It parses eight
programming languages. It reasons across seven scientific domains.
It learns on the device, retains all user data on the device, and
at scale, costs approximately fifteen pence per user per month.

We believe it represents a material opportunity for Arm.

## Why Arm

Arm powers the substantial majority of the world's mobile devices.
The commercial logic follows naturally.

If capable, private AI runs exclusively on Arm — because it was
architected for Arm, validated on Arm, and demonstrated on Arm —
then Arm becomes essential infrastructure for every device
manufacturer seeking on-device intelligence.

MKAngel was designed with this in mind:

- **Pure CPU inference.** O(n) linear time complexity. No graphics
  processor. No dedicated neural processing unit. Arm Cortex-A is
  sufficient and, we would suggest, optimal.
- **37 megabytes.** The complete system — grammar engine, generative
  model, lexicon, and user data — occupies less storage than a
  single photograph. It will run on any Arm-based device
  manufactured in the past decade.
- **Twelve natural languages** — including Irish Gaelic, Welsh,
  Scots Gaelic, Hindi, Urdu, Bengali, Punjabi, and Polish — with
  planned expansion to French, Cantonese, Te Reo Maori, Samoan,
  and Indigenous Australian and Inuit languages. Each language
  added extends the commercial relevance of Arm silicon in that
  market.

## The Broader Position

The industry is moving, with some urgency, toward on-device AI.
Apple, Google, and Qualcomm are each investing billions in
transformer-based models that require dedicated neural processing
units, gigabytes of storage, and considerable power draw.

We have demonstrated that a fundamentally different architecture —
grammar-based structural inference — achieves genuine language
comprehension at a fraction of the resource requirement. This is
not an incremental efficiency gain. It is a distinct approach to
the problem, and one which favours Arm's established strengths:
power efficiency, ubiquity, and manufacturing scale.

We would respectfully suggest that the organisation best positioned
to own the reference implementation of efficient on-device AI on
Arm silicon will enjoy a considerable advantage for the coming
decade of personal computing.
